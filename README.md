# OCR Slip — สแกนใบเสร็จและสลิปโอนเงิน → CSV

เว็บแอปสำหรับสแกน **ใบเสร็จ** และ **สลิปโอนเงิน** ผ่าน **กล้อง** หรือ **รูปภาพ** อ่านข้อความไทย/อังกฤษด้วย OCR
ดึงข้อมูลสำคัญออกมาให้อัตโนมัติ แก้ไขได้ แล้ว **ส่งออกเป็นไฟล์ .csv**

- ประมวลผลในเบราว์เซอร์ทั้งหมด **ไม่มีเซิร์ฟเวอร์ ไม่บันทึกลงฐานข้อมูล** (ข้อมูลหายเมื่อปิด/รีเฟรชหน้า)
- OCR: [Tesseract.js](https://github.com/naptha/tesseract.js) ภาษา `tha+eng` (โหลดจาก CDN ครั้งแรก แล้วเบราว์เซอร์จะแคชไว้)

## ฟีเจอร์

| | |
|---|---|
| อินพุต | กล้อง (getUserMedia, กล้องหลังเป็นค่าเริ่มต้น, สลับกล้องได้), เลือกรูปหลายไฟล์, ลากวาง, วางจากคลิปบอร์ด |
| ปรับภาพ | ย่อ/ขยาย, ขาวดำ, ยืดคอนทราสต์, Otsu threshold (ปิดได้) |
| แยกประเภท | ใบเสร็จ / สลิปโอนเงิน (อัตโนมัติ เปลี่ยนเองได้) |
| ข้อมูลที่ดึง | ร้านค้า/ผู้รับ, วันที่ (รองรับ พ.ศ. และชื่อเดือนไทย), เวลา, ยอดรวม, ก่อนภาษี, VAT, เลขผู้เสียภาษี 13 หลัก, เลขอ้างอิง, จาก/ถึง, รายการสินค้า |
| ส่งออก | `CSV สรุป` (1 แถวต่อเอกสาร) และ `CSV รายการสินค้า` (1 แถวต่อรายการ) — UTF-8 BOM เปิดใน Excel ภาษาไทยไม่เพี้ยน, ป้องกัน formula injection |

## วิธีรัน

กล้องต้องใช้ผ่าน **HTTPS** หรือ **localhost**

```bash
npm start
```

แล้วเปิด http://localhost:8080 (หรือใช้ static server ใดก็ได้ เช่น `python3 -m http.server 8080`)
สามารถ deploy เป็น static site ได้ทันที เช่น GitHub Pages, Netlify, Vercel

## ทดสอบ

```bash
npm test
```

## โครงสร้าง

```
index.html          หน้าเว็บ
css/style.css       ดีไซน์ (Times New Roman, เส้น 1px ดำ, มุมเหลี่ยม, light/dark)
js/app.js           UI, คิว OCR, แสดงผล/แก้ไข, ส่งออก
js/camera.js        จัดการกล้อง
js/preprocess.js    ปรับภาพก่อน OCR
js/ocr.js           Tesseract.js worker
js/parser.js        แปลงข้อความ OCR → ข้อมูลโครงสร้าง
js/csv.js           สร้าง/ดาวน์โหลด CSV
tests/              unit tests (node:test)
```

## ข้อจำกัด

- ความแม่นยำขึ้นกับคุณภาพภาพ: ถ่ายให้ตรง สว่างพอ ไม่เบลอ และให้ใบเสร็จเต็มกรอบ
- ตัวแยกข้อมูลใช้กฎ (keyword + regex) อาจพลาดกับรูปแบบใบเสร็จแปลก ๆ — ตรวจและแก้ค่าก่อนส่งออก
